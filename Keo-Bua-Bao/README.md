# Kéo Búa Bao

Yêu cầu: Windows, Python và webcam; có Internet khi cài thư viện.

1. Giải nén toàn bộ dự án.
2. Mở `CAI_DAT.bat` và chờ cài đặt xong (chỉ cần lần đầu).
3. Mở `CHAY_GAME.bat` để chạy chương trình.

Đặt mỗi tay ở một nửa màn hình. Bấm **phím cách** để bắt đầu, **R** để đặt lại điểm, **Esc** để thoát.

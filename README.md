# Kéo Búa Bao

Yêu cầu: Windows, Python và webcam; có Internet khi cài thư viện.

## Cách chạy

1. Giải nén toàn bộ dự án.
2. Mở `CAI_DAT.bat`, đợi cài đặt hoàn tất (lần đầu).
3. Mở `CHAY_GAME.bat` để chạy chương trình.

## Cách chơi

- Đặt mỗi tay ở một nửa màn hình.
- Bấm **phím cách** để bắt đầu.
- Bấm **R** để đặt lại điểm.
- Bấm **F11** để bật/tắt toàn màn hình.
- Bấm **Esc** để thoát.
